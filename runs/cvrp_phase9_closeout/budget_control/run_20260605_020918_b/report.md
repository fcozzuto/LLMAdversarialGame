| **Fixed-Baseline Context**      | Clarke-Wright Savings was the best baseline with 100% feasibility, lowest feasible gap (0.074), and moderate runtime (76 ms), outperforming nearest neighbor (gap 0.273) and regret insertion local search (gap 0.466 but with much longer runtime ~1.38s). |
| **Feasibility**                 | All baselines and replay solver reached 100% feasibility; direct generation and budget-matched no replay failed completely. |
| **Objective Gap**               | Clarke-Wright Savings baseline had the smallest objective gap (0.074), replay solver matched nearest neighbor gap (0.273), others worse. |
| **Runtime**                    | Nearest neighbor fastest (42 ms), Clarke-Wright moderate (76 ms), replay slower (140 ms), regret insertion slowest (~1.38 s). Direct and budget-matched no replay were ~220-235 ms but infeasible. |
| **Robustness Across Families** | Clarke-Wright had the lowest robustness dispersion (0.0078), implying stable performance; others comparable or worse. |
| **Learned Condition vs Baselines** | No learned condition (direct synthesis, replay) clearly outperformed the best fixed baseline (Clarke-Wright Savings). Learned methods either matched weaker baseline or were infeasible. |
| **Replay vs No-Replay Control** | Replay-aware solver yielded feasible solutions with gaps similar to nearest neighbor but worse than Clarke-Wright, while no-replay control failed feasibility entirely. Replay was better than no-replay control but did not beat the best fixed baseline. |

### Conclusion

- **The Clarke-Wright Savings baseline is the best performer, balancing feasibility, low gap, and reasonable runtime.**
- **Learned direct synthesis and budget-matched no-replay methods failed feasibility.**
- **Replay-assisted search improves feasibility over no-replay but does not surpass Clarke-Wright baseline performance.**
- **No learned method clearly beats fixed baselines in objective gap or robustness.**
